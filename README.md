# MARTIAL | Luxury Athletic & Performance Apparel

A luxury e-commerce web application inspired by **Charcoal** (`charcoal.com.pk`) featuring the complete product catalog of **Wellstuff Industries** (`wellstuff.biz`).

## Features
- **612 Products & 77 Subcategories** across 7 sports & apparel categories.
- **British Pounds (£ GBP) & Pakistani Rupees (Rs. PKR)** dual currency system with live switcher.
- **eBay UK (`ebay.co.uk`) & Amazon (`amazon.com` / `amazon.co.uk`)** price verification on all products with direct comparison links.
- **Slide-over Shopping Cart Drawer** with Free Delivery progress meter.
- **Interactive Quick View Modal** with multi-image gallery zoom and color/size pills.
- **Predictive Real-time Search** across all 612 items by title, category, and SKU.
- **B2B Custom Team Kit Inquiry Builder**.
- **Responsive design** optimized for desktop, tablet, and mobile.

## Vercel Deployment
This repository is configured for one-click deployment on [Vercel](https://vercel.com).

1. Push this repository to GitHub, GitLab, or Bitbucket.
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import your repository.
4. Click **Deploy** (no build settings required - static HTML/CSS/JS).
